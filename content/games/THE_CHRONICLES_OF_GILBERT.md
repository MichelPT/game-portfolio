# The Chronicles of Gilbert

## Project facts

- **Date:** August 27, 2026
- **Engine:** Godot 4
- **Language used:** GDScript
- **Contribution:** Designed and implemented the UI; GDScript work was limited to this UI implementation

## Game concept

A real-time action card battler in which movement and dodge-rolling are basic actions while cards act as skills. The design combines deckbuilding choices with positioning, timing, and real-time execution.

## Public positioning

Be precise: use this project as evidence of Godot 4 familiarity, GDScript UI implementation, and UI design—not as evidence that Michel programmed the full combat system.
