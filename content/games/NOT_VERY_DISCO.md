# (Not) Very Disco

## Project facts

- **Date:** September 30, 2026
- **Event:** Very Disco Game Jam 2026
- **Theme:** “Compact”
- **Game:** https://obil.itch.io/not-very-disco
- **Jam:** https://itch.io/jam/very-disco-game-jam-2026-3
- **Roles:** Character artist and animator, visual-effects artist, UI designer and implementer, gameplay polish

## Design

A two-input reaction game set on a crowded dance floor. Friend means tap left; pickpocket means tap right. Difficulty grows through faster arrivals and smaller reaction windows. The game uses visual, audio, and haptic feedback, with Reduce Motion and separate BGM, SFX, and haptic settings.

## Contributions

- Created every character sprite and character animation.
- Created visual effects.
- Designed and implemented the UI.
- Polished the moment-to-moment gameplay response.

## Playtest and polish

- Tested a playable prototype.
- Feedback showed that impacts needed to feel stronger and the experience needed more competitiveness.
- Revised and redrew animations to feel snappier and more satisfying.
- Added impact techniques such as hit stop to make successful actions read and feel more clearly.

## Public positioning

Use this project as evidence of game feel, animation-driven feedback, rapid polish, UI implementation, accessibility awareness, and responding directly to prototype feedback.
